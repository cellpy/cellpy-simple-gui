# Issue #169: Compare selected cells

Source: https://github.com/cellpy/cellpy-simple-gui/issues/169

## Original issue text

We have the possibility to create a plot from one cell and tune that a bit in the cell explorer. Could we have a mode where we are allowed to pick several different cells? It could be valuable to have a plot/figure where we for example focus on one specific cycle from one cell, and compare it with another cycle from a different cell. And similar things.
