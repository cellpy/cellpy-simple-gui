# Issue #160: Add option to use OtherPath for loading files from remote directory

Source: https://github.com/cellpy/cellpy-simple-gui/issues/160

## Original issue text

One of our respected users would like to use cellpy-simple-gui for looking at his data. However, his raw-files are on a remote folder (only accesss through ssh).  Create a plan for how to implement functioning `OtherPath` solution for cellpy-simple-gui.
